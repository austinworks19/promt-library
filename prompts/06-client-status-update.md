# Prompt 06: Client status update

# Prompt Text
Based on these internal project notes: [Rough cut done for scenes 1-3. Scene 4 edit still in progress, editor got sick for 2 days so we're behind. Client asked for color grade reference last week, still waiting on their reply for that. Expect full first cut ready by next Friday if no more delays.], write a short status update email to send to the client. Include: (1) What's been completed since the last update, (2) What's currently in progress, (3) Any delays or blockers (explain plainly, no jargon), (4) Next expected milestone with a rough date. Keep it reassuring but honest — don't downplay real delays. Under 120 words."

# Intended Workflow/Task
Converting internal project notes into a client status update with a consistent format, instead of a producer writing one from scratch everytime.

# Problem Being Solved
Clients often chase for updates because producers are busy with active production work and don't get around to proactively emailing status updates, which can create tension or make the company seem disorganised.

# Automation Potential
could be scheduled to run weekly (or at project milestones) pulling from whatever internal notes/tracker the team already updates, producing a draft ready for a quick review and send.

# Risks and Limitations
Could downplay a serious issue if the internal notes themselves are vague or optimistic — the AI can only summarise what it's given, not judge how bad a delay actually is; sensitive situations (e.g., a client complaint, budget overrun) should always be written personally rather than automated; tone needs checking so it doesn't sound falsely upbeat when there's a real problem.
