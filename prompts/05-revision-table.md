# Prompt 05: Revision Table for Editor

# Prompt Text
Turn the client feedback below into a revision table for the editor, with columns: Timestamp | Requested Change | Type (Specific/General/Unclear). If no timestamp is given for a note, leave that column blank and mark it General or Unclear instead. Format the table so it's ready to paste directly into a Notion page (Markdown table format). Example row: 0:15 | Speed up logo animation | Specific. Feedback: [PASTE CLIENT FEEDBACK]

# Intended Workflow/Task
Converting the client's feedback to a table so the editor can easily paste it into Notion.

# Problem Being Solved
Organizing messy and long client's feeback emails. Editor can easily identify the actionable notes.

# Automation Potential
Not really ideal. Need to fix the prompt according to the client's feedback complexity.

# Risks and Limitations
Table formats when paste into notion could be misorganized and lost context. Need to manually format the table.
