# Prompt 03: Post-shoot wrap report
# Prompt text: 
You are a production assistant for a creative agency. Based on these raw notes from today's shoot: [PASTE NOTES], write a wrap report including: (1) What was filmed vs what was planned (note any scenes missed or added), (2) Any equipment or crew issues that came up, (3) Outstanding items needed before the edit can start, (4) Action items with names attached if mentioned in the notes. Keep it factual and do not add opinions or assumptions about why something happened unless stated in the notes.

# Intended workflow/task: 
Turning rushed on-set notes into a clean wrap report for the team.

# Problem being solved:
Wrap reports get delayed or skipped because no one wants to write them up after a long shoot day. Wrap reports are often either being neglected and skipped, or written up in a messy and inconsistent formats. 

# Automation potential:
still depends on someone actually taking notes on set.

# Risks and limitations:
Only as good as the notes given; shouldn't go to a client without a producer reviewing it first.
