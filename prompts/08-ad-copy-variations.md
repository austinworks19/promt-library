# Prompt 08: Ad Copy Variations for Campaign Testing

# Prompt Text
I'm testing ad copy for a new campaign on [PLATFORM, e.g., Instagram ads]. Here's the brief: [PASTE BRIEF — product, key message, audience]. Give me 5 short ad lines (under 40 words each) that I can A/B test against each other. Make sure each one takes a genuinely different approach — don't just reword the same angle five times. Try things like: leading with the benefit, telling a mini story, creating urgency, using social proof, or just being straightforward and simple. If there's no real testimonial, stat, or proof point in the brief, skip that angle rather than making something up

# Intended Workflow/Task
Generating multiple ad copy angles quickly for A/B testing a new campaign, instead of the marketing team writing each variation manually from scratch.

# Problem Being Solved
Testing different ad angles usually requires writing several versions by hand, which takes time and often results in variations that are too similar to each other to give useful test data.

# Automation Potential
High — can be triggered as soon as a campaign brief is finalised, producing a full test set of ad copy ready to load into the ad platform.

# Risks and Limitations
Urgency or social-proof style lines risk sounding exaggerated or misleading if not carefully worded, so each variation needs a compliance/brand check before running; only generates the copy, not which version will actually perform best; may still repeat similar phrasing if the brief itself is thin on detail.
