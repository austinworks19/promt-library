# Prompt 01: Client Brief Summary & Production Checklist

# Prompt Text
"You are a production coordinator at a creative agency. Read the following client brief: [PASTE CLIENT BRIEF/EMAIL]. Summarise it into: (1) Project goal in one sentence, (2) Key deliverables with formats (e.g., 30s video, 3 social cutdowns), (3) Deadline and any milestone dates mentioned, (4) Budget constraints if stated, (5) A checklist of pre-production tasks needed (crew, location, equipment, permissions) based on the brief".
